# BlueChip Machining Website

This folder is ready to upload to the root of the `bluechip-machining` GitHub repository.

## Files
- `index.html` — homepage
- `privacy.html` — Google Play privacy policy URL
- `support.html` — support/contact page
- `releases.html` — release notes
- `style.css` — shared styling
- `assets/` — logo, promotional art and screenshots

## GitHub Pages
1. Upload all files/folders to the repository root.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select **main** and **/(root)**.
5. Save.

Your privacy policy URL will be:
`https://YOUR-USERNAME.github.io/bluechip-machining/privacy.html`
