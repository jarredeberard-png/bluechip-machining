RELEASE ROADMAP

Built to keep growing.

The core app comes first. Favorites, advanced tools and broader shop features follow.

V1.0 — Initial Release

The complete core BlueChip Machining app and the foundation for everything that follows.

  • Core machining calculators including Calculator, bolt circles, 3-wire measurement, feeds & speeds, tap drills, thread pitch, geometry, tolerance and shop calculators
  • CNC programming references and tools including G-code, M-code, canned cycles, subprograms, Macro B, G75 and G76 builders
  • Machinist tips and quick-reference information
  • Local Shop Notes
  • Searchable, categorized navigation
  • Blue-and-black dark interface with orange accents and custom machining graphics
  • Android-focused first release

V1.1 — Favorites, Recent, Search & History

The first quality-of-life update after launch.

  • Favorites for commonly used calculators and references
  • Recently used tools
  • Expanded app-wide search
  • Calculation and search history

V1.2 — Advanced Machining Tools

Expanded geometry, tolerance and fit tools, plus additional shop utilities driven by real use and feedback.

Future — Shop & CNC Expansion

  • Jobs and job-specific information
  • Cutting-tool and holder library
  • Machine profiles
  • Expanded CNC program generation

Long-Term — BlueChip Machining Platform

  • Community features for machinists
  • BlueChip Machining Assistant for calculations, references, troubleshooting and shop questions
  • Continued calculator, CNC and reference expansion
